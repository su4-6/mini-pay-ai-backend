01关于我 / About

我怎么写代码，以及我在意什么

关注方向

  • 支付编排与对账
  • 钱包与复式账本
  • 微服务边界划分
  • 分布式一致性
  • 边缘接入与部署

我做的事情集中在资金相关的系统上：一笔支付从下单、扣款、回调到对账，中间会经过好几个服务，每一步都可能重复、超时或者失败。我喜欢把这类问题拆干净——谁拥有这份数据、状态机怎么流转、哪一步必须幂等、出错了从哪里补——然后再写代码。

工程上我倾向于约束自己：服务之间只通过版本化接口和可靠事件协作，不跨库查询；余额和账本由一个服务独占写入，读写落在同一个本地事务里；金额统一用整数存分，不做浮点运算；纠错只允许冲正，不允许直接改数。这些规则听起来啰嗦，但它们决定了系统在出错的时候是可控的还是失控的。

除了后端，我也会把整套东西自己部署起来：K3s 上跑服务与中间件，网关负责路由和 TLS，Cloudflare 放在最外层做 DNS、证书和静态内容分发。B 端控制台用 React + umi 写，消费者端是一套 H5（同样是 React + umi，短信登录、流式 AI 对话、钱包与转账都在里面）。全链路自己走一遍，才知道哪些设计只是看起来合理。
